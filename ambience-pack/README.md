# ambience-pack — звук для «дибитишки» (и любой другой сцены)

Готовый набор: **реальные записи природы (CC0) + генеративная мелодия**.
Задача была «сделать музыку мелодичнее, звук леса взять файлами и вставить
аккуратно, чтобы не звучало механически» — вот пакет, который это решает,
и бриф, как перенести его в проект.

## Что здесь есть

```
ambience-pack/
├── assets/              7 готовых петель .m4a (≈2,5 МБ на всё) — можно класть в приложение как есть
│   ├── sea.m4a          волны, 38,5 с
│   ├── rain.m4a         дождь, 50 с
│   ├── hearth.m4a       костёр, 42 с
│   ├── forest.m4a       утро в лесу, 37 с
│   ├── lullaby.m4a      очень тихая вода, 32 с
│   ├── space.m4a        высокий «шёпот», 52 с
│   └── chimes.m4a       настоящие колокольчики (редкие акценты), 7,5 с
├── demo/                эталон звучания: страница в браузере (мелодия + записи)
│   ├── index.html
│   └── engine.js        движок-образец: подложка из файлов + мотивная мелодия
├── tools/
│   ├── build-ambience.sh  пересборка всего с нуля (качает CC0-записи и собирает петли)
│   ├── loopify.mjs        сборка бесшовной петли (кроссфейд, нормировка, отчёт)
│   ├── recipes.json       параметры петель по сценам
│   └── serve.mjs          крошечный сервер для прослушивания демо
├── work/out/report.json   метрики каждой петли (RMS, пик, отклонение стыка)
├── LICENSES.md            происхождение и лицензии записей (CC0 1.0)
└── ZADANIE.md             бриф: что и как менять в проекте (главный документ)
```

## Послушать

```bash
node tools/serve.mjs 8080
# открыть http://localhost:8080/demo/
```

Выберите сцену, нажмите «Играть» и послушайте 20–30 секунд в наушниках.
Внизу страницы видно, какой аккорд звучит и какой мотив ведёт мелодию.

## Пересобрать звук

```bash
bash tools/build-ambience.sh
```

Скрипт сам скачает исходные CC0-записи, приведёт их к 48 кГц/моно, соберёт
бесшовные петли, закодирует в AAC и покажет отчёт по громкости. Нужны `node`,
`git`, `gh` или `curl`; `ffmpeg` поставится из npm, если его нет.
