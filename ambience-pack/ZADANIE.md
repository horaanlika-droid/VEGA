# Бриф: «звук природы файлами + мелодичнее»

Документ для новой сессии на репозитории **`horaanlika-droid/secrdddd`**
(приложение «дибитишка», экран `#/sound`, файл `app/js/ambient.js`).

## 1. Что просил владелец

> «Нужно более мелодично сделать музыку. И звук леса и т.д. — найти аудиофайлами
> и аккуратно интегрировать, чтоб не звучало механически.»

Расшифровка задачи:

1. **Мелодичнее.** Сейчас это «полотно»: аккорды из расстроенных синусов и шум
   воздуха. Мелодии нет вообще — отсюда ощущение генератора. Нужен голос: короткий
   мотив, который повторяется и меняется вместе с аккордами.
2. **Звук природы — реальными записями.** Волны, дождь, костёр, лес, птицы:
   заменить фильтрованный шум (сцена `texture` в `AMBIENT_SCENES`) на записи.
3. **Не механически.** Ничто не должно читаться как петля: длинные петли, две-три
   копии со случайными входами, несинхронные «дыхания», редкие живые акценты,
   человеческие задержки в мелодии.

Готовый звук и код-образец лежат в папке `ambience-pack` (её передали вместе с
этим брифом): `assets/*.m4a`, `demo/engine.js`, `LICENSES.md`, `work/out/report.json`.

## 2. Что уже готово (не надо делать заново)

- **7 петель** (морские волны, дождь, костёр, лес с птицами, тихая вода для
  колыбельной, высокий «шёпот» для космоса, колокольчики для акцентов), **CC0 1.0**,
  ≈2,5 МБ; одна сцена — 321–521 КБ.
- Петли бесшовные: кроссфейд 5–12 с, проверка по огибающей вокруг склейки —
  отклонение 0,1–4,3 дБ (`work/out/report.json`).
- Громкость выровнена: RMS −27…−33 dBFS, мягкий лимитер −1,5 dBFS, интегрированная
  громкость −26,2…−30,9 LUFS.
- **Демо-движок** `demo/engine.js` — эталон того, как это должно звучать и как
  устроено: слои «земля» (файлы) / «полотно» (аккорды) / «голос» (мотив) + акценты.
- **Пересборка с нуля**: `bash tools/build-ambience.sh` (качает CC0-записи, собирает
  петли, кодирует, печатает отчёт). В песочнице `raw.githubusercontent.com`
  недоступен — скрипт использует `git clone` и `gh api .../git/blobs`, это рабочий путь.

## 3. Куда класть файлы в проекте

```
app/assets/ambience/sea.m4a  rain.m4a  hearth.m4a  forest.m4a  lullaby.m4a  space.m4a  chimes.m4a
```

- Бот (`bot/`) звук не трогает — только веб-приложение.
- Обновить `scripts/check-project.mjs`: файлы на месте, размеры в разумных
  пределах (например, каждый 250–600 КБ, суммарно ≤ 3 МБ), лишних нет.
- **README честно переписать**: сейчас там заявлено «Ни одного аудиофайла» и
  «ноль мегабайт ассетов» — это перестаёт быть правдой. Формулировка примерно:
  «звук — открытые записи (CC0, ≈2,5 МБ); файл сцены подгружается при её выборе,
  а шумовой генератор остаётся запасным вариантом без сети». То же — в комментарии
  к движку в `app/js/app.js` (там повторяется «ноль мегабайт»).

## 4. Что менять в `app/js/ambient.js`

### 4.1. Слой «земля» вместо `buildTexture()`

Сохранить публичный API (`AMBIENT_SCENES`, `sceneById`, `createAmbientEngine(deps)`,
`onStatus`, `settings.texture` = ползунок «Воздух», `settings.reverb`, стоп/перезапуск,
таймер, «без конца») и добавить загрузку записи:

```js
// deps.loadBed(file) -> Promise<AudioBuffer>  — подставляется в тестах фейком,
// тогда npm run ambient-test идёт без сети и без декодера.
async function buildBed(scene, startAt) {
  const buf = await loadBed(scene.bed.file);      // кэш в Map по пути файла
  bedNodes = [];
  for (let i = 0; i < 2; i++) {                   // две копии — фазы никогда не совпадут
    const src = ctx.createBufferSource();
    src.buffer = buf; src.loop = true;
    src.start(startAt, Math.random() * buf.duration);
    const tone = biquad('lowpass', scene.bed.tone, 0.4);
    const gain = ctx.createGain(); gain.gain.value = bedLevel(scene) / 2;
    const lfo = addLfo(scene.bed.drift[i], bedLevel(scene) * 0.22, gain.gain); // 25–49 с, свои фазы
    const pan = ctx.createStereoPanner(); pan.pan.value = (i ? 1 : -1) * scene.bed.spread;
    src.connect(tone).connect(gain).connect(pan).connect(dry);
    if (verbIn) gain.connect(verbIn);
    bedNodes.push(src, lfo);
  }
}
```

- `bedLevel(scene) = scene.bed.level * settings.texture` — ползунок «Воздух» остаётся
  рабочим (он и раньше управлял только слоем сцены).
- **Фолбэк обязателен**: если `loadBed` упал (нет сети / старый WebView) — включать
  прежний шумовой слой (`noiseBuffer` + `texture.paths`) на низком уровне. Тест
  «буфер шума зацикливается без щелчка» тогда остаётся в силе.
- Смена сцены на ходу: гасить старые узлы за 1,5–2,5 с (как сейчас `stopTexture`),
  потом собирать новые — никаких резких обрывов.
- Предзагрузка: файл текущей сцены — сразу, следующий по списку — лениво (в простое,
  через `requestIdleCallback`), чтобы переключение ощущалось мгновенным.

### 4.2. Новый слой «голос» (это и есть «мелодичнее»)

Готовый образец — `demo/engine.js`, функции `makeMotif()`, `scaleNote()`,
`chordDegrees()`, `bell()`, `phrase()`. Правила, которые делают музыку музыкой:

| Правило | Значение |
|---|---|
| Мотив | 3–5 шагов по ладу, сочиняется **один раз на сессию** и потом транспонируется под аккорд |
| Лад сцены | мажор / натуральный минор / дорийский / лидийский — из `demo/engine.js` |
| Финал фразы | всегда устойчивая ступень (тоника/терция/квинта) — фраза «закрывается» |
| Регистр | MIDI 64–98 (на 1–2 октавы выше полотна), у колыбельной ниже |
| Фраза | 3–5 нот, длительности 1,4 / 2,2 / 3,1 / 4,2 с, последняя нота в 1,5 раза длиннее и тише |
| Дыхание | внутри фразы случайная пауза 0,9–2,4 с; между фразами 8–26 с (колыбельная — 16–34 с) |
| Человечность | сдвиг нот ±60…90 мс, разброс громкости 0,62–1,0, дышащая нестройность ±4 цента |
| Подголосок | иногда (≈45 %) одна нота на 5–12 полутонов ниже, тише вдвое — слышится «написанная» музыка |
| Тембр | 4 частичных тона (1 / 2,01 / 3,02 / 4,98) с атакой 12–30 мс и хвостом 1,6–4 с; мягкий lowpass 3,2 кГц; эхо — существующий `conv` |
| Запрещено | барабаны, ритм, сетка, «арпеджио» каждые 2 секунды |

Ползунок: если владелец захочет, добавить «Голос» (0…1) рядом с «Воздухом»;
по умолчанию 0,15–0,19 от общей громкости.

### 4.3. Живые акценты

`chimes.m4a` (настоящие колокольчики) — раз в 40–180 с, уровнем 0,04–0,08,
своя панорама, вход 3–6 с, уход 4–6 с. Это «случайность», которую невозможно
предсказать, и она очень дешёвая по весу файла (76 КБ).

  — «у каждой сцены есть лад, прогрессия и записи»,

## 5. Чек-лист «не звучит механически»

- [ ] петли длинные: 32–52 с (короткие записи не берём — 4-секундный дождь слышен сразу);
- [ ] минимум две копии петли со случайными точками входа;
- [ ] ни один LFO/дыхание не синхронизированы между собой (периоды 25–49 с, разные фазы);
- [ ] акценты и фразы **не** на сетке: только случайные величины;
- [ ] переход между сценами — кроссфейд 1,5–2,5 с, без щелчков;
- [ ] суммарный вес ≤3 МБ, загрузка по сцене;
- [ ] если запись не загрузилась — тихий шумовой фолбэк, а не тишина и не ошибка.

## 6. Если понадобится другой/свой звук

Требования: **CC0 / public domain** (тогда никаких уведомлений в приложении),
от 30 с, ровный фон без речи, музыки и щелчков монтажа. Свободные источники:
freesound.org (фильтр CC0), archive.org (public domain), Wikimedia Commons,
OpenGameArt (CC0), собственные записи. Добавить слой в `tools/recipes.json` и
прогнать `bash tools/build-ambience.sh` — петля соберётся сама.

## 7. Порядок работ

1. Разложить `assets/*.m4a` → `app/assets/ambience/`, обновить `check-project.mjs`.
2. В `AMBIENT_SCENES` заменить `texture` на `bed` (+ сохранить `texture` для фолбэка),
   добавить `mode` / `progression` / `chordSec` / `melody` / `accents` / `reverb`
   (значения — из `demo/engine.js`, они уже выверены).
3. Реализовать `buildBed` и слой «голос», сохранив публичный API движка.
4. Обновить тесты (`ambient-test`, `dom-smoke`, `browser-smoke`) и README.
5. `npm run verify`, затем PR от ветки сессии `arena/...-secrdddd`.

## 8. Что делать не нужно

- Не подключать стриминг и внешние URL — звук должен лежать в репозитории.
- Не использовать записи без явной лицензии (всё, что «скачано из интернета»).
- Не тянуть треки по 5–10 МБ и не держать все сцены в памяти: только текущая.
- Не убирать шумовой генератор целиком: это фолбэк для офлайна и старых WebView.
